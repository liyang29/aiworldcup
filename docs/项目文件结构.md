# 项目文件结构

> 世界杯 AI 预测竞技场（predworld.fun）的代码目录说明。
> 配合《项目进度表.md》《技术规格》《设计规范》《上线与运营清单》一起看。
> 技术栈：Next.js 14 (App Router) + Tailwind + Supabase + OpenRouter + football-data.org，Vercel 部署，GitHub Actions 跑定时任务。

---

## 顶层目录速览

```
aiworldcup/
├─ src/                  前端 + 服务端（Next.js App Router）
├─ scripts/              后台批处理（预测 / 结算 / 同步），Node 脚本，跑在 GitHub Actions
├─ supabase/             数据库迁移 SQL（建表 / RLS / 触发器）
├─ docs/                 项目文档（进度、规格、设计、上线、本结构说明）
├─ .github/workflows/    GitHub Actions 定时任务（cron）
├─ public/               静态资源（models/ 模型 logo、flags/ 国旗）
├─ .claude/              Claude Code 本地配置（hook 等）
├─ DESIGN.md             设计 token（x.ai/Grok 暗色风）
├─ .env.example          环境变量样板（真实值在 .env.local，已 gitignore）
└─ 各类配置             next.config / tailwind.config / tsconfig / package.json 等
```

## scripts/ — 后台批处理（Node，跑在 GitHub Actions）

> 用 service_role key（仅在此，**绝不进前端 / Vercel**，对应铁律4）。用 `.mjs`（ESM）。

```
scripts/
├─ config/
│  ├─ models.mjs                    10 个参赛模型清单（名称 / 厂商 / active 开关，换平台只改这里）
│  └─ provider.mjs                  OpenRouter 接入配置（base URL / key / 是否启用联网搜索）
│
├─ lib/
│  ├─ prompt.mjs                    buildPrompt()：统一 system+user 提示词（铁律2：所有模型同输入）
│  ├─ llm.mjs                       callModelJSON()：调模型 + 重试 + :online 搜索 + 解析 JSON
│  ├─ scoring.mjs                   算分规则（精确5/对方向3/对平局1/错0，淘汰赛晋级+2）
│  └─ supabase-admin.mjs            service_role 客户端（后台写库用）
│
├─ predict/index.mjs                预测主流程：取近 N 小时未预测比赛 → 调各模型 → 写库（跳过已预测）
├─ settle/index.mjs                 结算：拉真实比分 → 对每条预测算分 → 回写 points
├─ sync/index.mjs                   同步赛程 / 比分（football-data.org → matches 表）
├─ sync/squads.mjs                  同步参赛队 26 人名单（API-Football）
├─ seed/models.mjs                  把 models.mjs 写入数据库 models 表
├─ db/apply.mjs                     执行 supabase/migrations 下的 SQL
├─ hooks/progress-reminder.mjs      提交时提醒核对进度表（Claude Code hook）
└─ test/region-check.mjs            诊断脚本：测各模型可达性 + 出口 IP
```

## 关键约定（红线）

- **service_role key 只在 `scripts/` + GitHub Actions Secrets**，绝不进 `src/` / Vercel 环境变量（铁律4）。
- **`.env.local` 永不提交**（已 gitignore）；样板见 `.env.example`。
- **所有模型同一份输入**（`scripts/lib/prompt.mjs`，铁律2）；预测**开赛前锁定**、锁后不可改（RLS + 触发器，铁律1）。
- UI **不用 emoji**，图标统一 Tabler；品牌 logo 走 `public/models/`。
- **无提现 / 现金 / 加密入口**（铁律8）。
