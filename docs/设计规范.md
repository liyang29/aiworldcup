# 设计规范 · 世界杯 AI 预测竞技场

> 风格基调：**x.ai / Grok 暗色宇宙感**（engineered-cosmic，冷峻不花哨）。
> 完整设计 token 见项目根目录 [`DESIGN.md`](../DESIGN.md)（Google Stitch 的 DESIGN.md 格式，供 AI 据此生成风格一致的 UI）。
> 本文件是给人看的精简版 + 项目专属约定。

## 一、核心原则

1. **暗色为底**：近黑画布，白字，留白克制，工程+宇宙的冷峻感。
2. **点缀色少而精**：橙（日落）/ 紫（暮色）只用在 CTA、强调、第一名等关键处，绝不大面积铺。
3. **移动端优先**（铁律6）：所有布局先保证手机好看。
4. **图标用图标字体，禁用 emoji**：统一用 **Tabler outline** 图标（如 `ti-trophy`、`ti-ball-football`），不要用 🏆⚽ 这类 emoji。

## 二、颜色 token（关键）

| 用途 | 值 |
|---|---|
| 画布底色 canvas | `#0a0a0a` |
| 卡片底 canvas-card | `#191919` |
| 次级面 canvas-soft | `#1a1c20` |
| 主文字 ink | `#ffffff` |
| 正文 body | `#dadbdf` |
| 弱文字 / 静音 mute | `#7d8187` |
| 分隔线 hairline | `#212327` |
| 主按钮（白底黑字 pill） primary | `#ffffff` / on `#0a0a0a` |
| 强调·日落橙 accent-sunset | `#ff7a17` |
| 强调·暮色紫 accent-dusk | `#7c3aed` |

> 本项目约定：**第一名/最强模型用日落橙高亮**，CTA 主按钮可用橙 pill 或白 pill。

## 三、字体

- 显示/标题：几何无衬线（`Universal Sans` → 回退 `Inter, system-ui`），字重 400-500，负字距。
- 正文：同族无衬线，16px / 行高 1.5。
- 说明性小标签（eyebrow）：等宽大写 + 字距加宽（`GeistMono`/`ui-monospace`，letter-spacing ~1.4px，uppercase）。

## 四、圆角 & 间距

- 圆角：`sm = 8px`（卡片/输入框）、`pill = 9999px`（按钮）。其余直角。
- 间距阶梯：2 / 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px。

## 五、组件基线

| 组件 | 规则 |
|---|---|
| 主按钮 | 白底黑字，pill，padding 4×12 |
| 描边按钮（暗底） | 透明底、白字、hairline 边、pill |
| 卡片 | `#191919` 底、hairline 边、圆角 8、padding 24 |
| 导航 | canvas 底、白字、body-sm |
| eyebrow 小标签 | 等宽大写、字距加宽 |
| 分隔线 | hairline `#212327` |

## 六、图标方案（重要约定）

- **库**：[Tabler Icons](https://tabler.io/icons)（outline 线性款），React 项目用 `@tabler/icons-react`。
- **禁用 emoji**：标题、按钮、列表前缀等一律用 Tabler 图标，不用 emoji。
- 常用：奖杯 `IconTrophy`、足球 `IconBallFootball`、对阵 `IconVs`/`IconSwords`、上升 `IconArrowUp`、机器人 `IconRobot`、用户 `IconUser`、分享 `IconShare`。
- 尺寸：行内 16-20px，装饰 ≤24px；颜色继承父级或用强调色。
